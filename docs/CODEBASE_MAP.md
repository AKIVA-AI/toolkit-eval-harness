# Codebase map

```text
src/toolkit_eval_harness/
  cli.py            argparse CLI (`toolkit-eval`); exit codes; run-time pack/signature checks
  __main__.py       `python -m toolkit_eval_harness`
  __init__.py       public exports and __version__
  suite.py          EvalSuite / EvalCase; parse_suite(), read_suite_dir()
  runner.py         run_suite(): required-scorer resolution, fail-closed case aggregation
  scoring.py        exact_match_score(), json_required_keys_score(), JSONSchema
  scorers.py        configurable built-in scorers (SQuAD EM/F1, fuzzy, regex, numeric, JSON Schema,
                    opt-in LiteLLM embedding + judge)
  plugins.py        scorer registry (register_scorer, entry-point discovery)
  report.py         EvalReport (reads legacy reports and eval.run envelopes) + JSON writer
  envelope.py       report envelope v1: canonical JSON, in-toto Statement builder, validator
  compare.py        compare_reports(): suite check, flips, per-tag, bootstrap-CI gate
  importers.py      promptfoo / Inspect AI / DeepEval results -> EvalReport (stdlib; zstd optional)
  stats.py          seeded paired percentile bootstrap, type-7 quantile (stdlib only)
  pack.py           pack create / verify / in-memory load / extract; PackVerificationError
  signing.py        Ed25519 keygen, sign, verify (optional `cryptography`)
  hashing.py        streaming SHA-256
  io.py             path-validating read/write helpers used by the CLI
  formatters.py     json / table / csv / markdown output
  logging_config.py stderr logging (text or JSON)
  metrics.py        SuiteMetrics (used by runner); MetricsCollector (library only)
  health.py         check_health() (library only)
action.yml          composite GitHub Action: compare + job summary + optional PR comment
schemas/            report-envelope.v1.json (JSON Schema for the envelope)
tests/              pytest suite; test_envelope.py checks CLI envelopes against the schema; test_scoring_semantics.py and test_run_gating.py pin the
                    fail-closed scoring, pack verification and exit-code contracts
tests/fixtures/    importer samples generated by the real tools (see its README)
examples/           example suite, predictions and a library-usage script
```

## Data flow

```text
suite dir or pack.zip --(pack: signature check, manifest check, in-memory parse)--> EvalSuite
predictions.jsonl --(ids unique, `prediction` field present)--> {id: prediction}
run_suite: for each case, run every required scorer; score = min, passed = all == 1.0
  -> EvalReport {suite, summary, cases}
cli run: exit 0 if all cases passed, 1 otherwise; --out writes an eval.run envelope
compare_reports(baseline, candidate, CompareBudget) -> same-suite check, pair cases by id,
  flips + per-tag, paired bootstrap CI on the mean delta, fail if CI upper regression > budget
```
